# inbox(AI への受け渡し場所)

ここにファイルを置いて main に push(GitHub の画面から「Add file → Upload files」でも可)すると、
AI(Gemini など)が中身を読み、お知らせ記事・業績・メンバー情報に整えてプルリクエストを作ります。
内容を確認してマージすると、サイトに反映されます。

置けるものの例:

- `memo.txt` … 「10/4 UbiComp2026 で桂さんが口頭発表。タイトルは〜」のような走り書き
- `photo.jpg` … 記事に載せたい写真
- `refs.bib` … 論文や学会発表の BibTeX
- `members.txt` … 新しく配属されたメンバーの名簿

1回の push で複数のファイルを置いても大丈夫です。
